
# EduTechBridge

## Project Overview
EduTechBridge is a university resource-sharing
web application for students and teachers.

## Problem Statement
Students often find it difficult to collect
notes, PDFs, reference materials, syllabuses
and assignments from different sources.

## Proposed Solution
EduTechBridge provides one platform where
teachers can share educational resources and
students can access them easily.

## Target Users
1. University Students
2. University Teachers

## Main Features
- Student and teacher login
- Study notes and PDF resources
- Reference books and project materials
- Subject-wise syllabus
- Assignment creation and submission
- Online multiple-choice quizzes
- Search and filter resources
- Student and teacher dashboards

## Excluded Features
- Live classes
- Video conferencing
- Real-time chat

## Technology Stack
Frontend: HTML, CSS, JavaScript, React
Backend and Database: Supabase
Tools: VS Code, Git, GitHub

## Project Duration
90 days, 1 hour per day
